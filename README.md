# FastAPI Service

## Overview

Production-ready FastAPI service built on Python 3.12+, `uv` for dependency management, and a modular `src/` layout. The service exposes versioned API v1 health probes, users CRUD APIs, a draft-to-ready video post lifecycle, personal feed reads, Alembic migrations, and autogenerated OpenAPI documentation.

## Requirements

- Python 3.12+
- [`uv`](https://github.com/astral-sh/uv)
- Docker (optional)

## Quick Start

```bash
uv sync
cp .env.example .env
docker compose up -d postgres
uv run alembic upgrade head
uv run serve
```

The service starts on `http://localhost:8000`.

## API Documentation

- Swagger UI: `http://localhost:8000/api/docs`
- ReDoc: `http://localhost:8000/api/redoc`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`

## Users API

Base path: `/api/v1/users`

- `POST /api/v1/users`
- `GET /api/v1/users?page=1&limit=20`
- `GET /api/v1/users/{user_id}`
- `PATCH /api/v1/users/{user_id}`
- `DELETE /api/v1/users/{user_id}`

The API enforces unique emails, validates UUID path parameters through FastAPI/Pydantic, and returns `404` for missing users plus `409` for duplicate emails.

## Video Posts API

Base path: `/api/v1/posts`

- `POST /api/v1/posts`
- `POST /api/v1/posts/{post_id}/video-uploads`
- `POST /api/v1/posts/{post_id}/video-uploads/{upload_id}/complete`
- `GET /api/v1/posts/{post_id}`
- `GET /api/v1/users/{user_id}/feed`

Video posts move through `draft -> uploading -> processing -> ready|failed`. Playback metadata is emitted only when the processed asset reaches `ready`.

## Lifecycle Test Fixtures

The lifecycle suite lives in `tests/api/v1/test_video_post_lifecycle.py` and does not require checked-in media binaries.

- Upload initiation uses metadata-only request payloads instead of real files.
- Processing uses the in-process deterministic pipeline by default.
- Failure and "still processing" states are driven in tests via `app.state.video_pipeline` doubles, so CI does not depend on external encoders, storage, or timing-sensitive workers.
- The default limits mirror the v1 decision note: MP4 container, H.264 video, AAC-LC audio, 250 MiB max size, and 120 seconds max duration.

## Health Check Endpoints

### Liveness

```bash
curl http://localhost:8000/api/v1/health/live
```

Example response:

```json
{
  "status": "ok",
  "timestamp": "2026-05-26T12:00:00Z"
}
```

### Readiness

```bash
curl http://localhost:8000/api/v1/health/ready
```

Example response:

```json
{
  "status": "ready",
  "version": "1.0.0",
  "uptime_seconds": 1.234,
  "timestamp": "2026-05-26T12:00:00Z",
  "components": [
    {
      "name": "application",
      "status": "healthy",
      "latency_ms": 0.0,
      "details": "FastAPI application startup completed."
    }
  ]
}
```
