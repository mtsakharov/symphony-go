# FastAPI Service

## Overview

Production-ready FastAPI service built on Python 3.12+, `uv` for dependency management, and a modular `src/` layout. The service exposes versioned API v1 health probes, a users CRUD REST API, a per-user post indexing pipeline, Alembic migrations, and autogenerated OpenAPI documentation.

## Requirements

- Python 3.12+
- [`uv`](https://github.com/astral-sh/uv)
- Docker (optional)

## Quick Start

```bash
uv sync
cp .env.example .env
docker compose up -d postgres
uv run alembic upgrade head
uv run serve
```

The service starts on `http://localhost:8000`.

## API Documentation

- Swagger UI: `http://localhost:8000/api/docs`
- ReDoc: `http://localhost:8000/api/redoc`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`

## Users API

Base path: `/api/v1/users`

- `POST /api/v1/users`
- `GET /api/v1/users?page=1&limit=20`
- `GET /api/v1/users/{user_id}`
- `PATCH /api/v1/users/{user_id}`
- `DELETE /api/v1/users/{user_id}`
- `POST /api/v1/users/{user_id}/posts/index`

The API enforces unique emails, validates UUID path parameters through FastAPI/Pydantic, and returns `404` for missing users plus `409` for duplicate emails.

## Post Indexing

The indexing pipeline is scoped to a single user and persists chunk-level records keyed by `user_id`, `post_id`, and `chunk_id`.

V1 indexing rules in this repo:

- only that user's own posts are considered
- posts must be published (`published_at` set)
- archived or deleted posts are excluded
- empty normalized content is excluded

Long post content is normalized into stable plain text, chunked deterministically by paragraph and word boundaries, embedded with a deterministic local fallback generator, and stored in `post_index_records` for later retrieval/citation packaging.

## Health Check Endpoints

### Liveness

```bash
curl http://localhost:8000/api/v1/health/live
```

Example response:

```json
{
  "status": "ok",
  "timestamp": "2026-05-26T12:00:00Z"
}
```

### Readiness

```bash
curl http://localhost:8000/api/v1/health/ready
```

Example response:

```json
{
  "status": "ready",
  "version": "1.0.0",
  "uptime_seconds": 1.234,
  "timestamp": "2026-05-26T12:00:00Z",
  "components": [
    {
      "name": "application",
      "status": "healthy",
      "latency_ms": 0.0,
      "details": "FastAPI application startup completed."
    }
  ]
}
```
