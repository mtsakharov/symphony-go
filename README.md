# FastAPI Service

## Overview

Production-ready FastAPI service built on Python 3.12+, `uv` for dependency management, and a modular `src/` layout. The service exposes versioned API v1 health probes, a users CRUD REST API, Alembic migrations, and autogenerated OpenAPI documentation.

## Prerequisites

- Python 3.12 (`.python-version` pins `3.12`; `pyproject.toml` requires `>=3.12`)
- `uv` for dependency management and running project commands
- Docker Compose for the provided local PostgreSQL bootstrap (`docker compose up -d postgres`)

## Bootstrap

```bash
cp .env.example .env
uv sync
docker compose up -d postgres
uv run alembic upgrade head
uv run serve
```

The app loads settings from `.env`, and `.env.example` already defines the default local
`DATABASE_URL` for the provided PostgreSQL container on `localhost:5432`.

Equivalent Make targets are available for the synced environment, migrations, and app startup:
`make sync`, `make migrate`, and `make run`.

Use Docker Compose here only for the `postgres` service in the host-run flow above. The separate
`docker compose up --build` path is a full-container workflow, not the canonical bootstrap path.

The service starts on `http://localhost:8000`.

## API Documentation

- Swagger UI: `http://localhost:8000/api/docs`
- ReDoc: `http://localhost:8000/api/redoc`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`

## Users API

Base path: `/api/v1/users`

- `POST /api/v1/users`
- `GET /api/v1/users?page=1&limit=20`
- `GET /api/v1/users/{user_id}`
- `PATCH /api/v1/users/{user_id}`
- `DELETE /api/v1/users/{user_id}`

The API enforces unique emails, validates UUID path parameters through FastAPI/Pydantic, and returns `404` for missing users plus `409` for duplicate emails.

## Health Check Endpoints

### Liveness

```bash
curl http://localhost:8000/api/v1/health/live
```

Example response:

```json
{
  "status": "ok",
  "timestamp": "2026-05-26T12:00:00Z"
}
```

### Readiness

```bash
curl http://localhost:8000/api/v1/health/ready
```

Example response:

```json
{
  "status": "ready",
  "version": "1.0.0",
  "uptime_seconds": 1.234,
  "timestamp": "2026-05-26T12:00:00Z",
  "components": [
    {
      "name": "application",
      "status": "healthy",
      "latency_ms": 0.0,
      "details": "FastAPI application startup completed."
    }
  ]
}
```
