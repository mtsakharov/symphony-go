# FastAPI Service

Production-ready FastAPI service built with Python 3.12, `uv`, SQLAlchemy, and Alembic. It exposes versioned health probes, a users CRUD API, and autogenerated OpenAPI documentation.

## Features

- FastAPI application with versioned routing under `/api/v1`
- Health endpoints for liveness and readiness checks
- Users CRUD API with conflict and not-found handling
- SQLAlchemy data layer and Alembic migrations
- `uv`-managed local workflow with `ruff`, `mypy`, and `pytest`

## Requirements

- Python 3.12+
- [`uv`](https://docs.astral.sh/uv/)
- Docker and Docker Compose for local PostgreSQL

## Quick Start

```bash
uv sync
cp .env.example .env
docker compose up -d postgres
uv run alembic upgrade head
uv run serve
```

The API starts on `http://localhost:8000`.

## API Documentation

- Swagger UI: `http://localhost:8000/api/docs`
- ReDoc: `http://localhost:8000/api/redoc`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`

## Main Endpoints

Base path: `/api/v1`

- `GET /health/live`
- `GET /health/ready`
- `POST /users`
- `GET /users?page=1&limit=20`
- `GET /users/{user_id}`
- `PATCH /users/{user_id}`
- `DELETE /users/{user_id}`
